Etch — Logo & Icon Concepts

Directional vector concepts. Core idea: your run etches a glowing line into the map. Ember (#fc5c44) on ink, dark-mode-first — the same accent as the app's "recent-run glow."

App icon directions

A · Route-E
The letter E drawn as one running route + a GPS start dot. Distinctive, verbable.
B · Trace-E (organic)
Same idea with real GPS-trace wobble — friendlier, more "human run."
C · Glow-web
One ember route lit up over faint streets — literally the app in a tile.
D · Ember tile
Inverted lockup for stickers, the marketing site, and a light-mode alt.

These are vector directions, not final art — each is exportable to the required 1024×1024 icon and a monochrome variant. My pick: A (Route-E) for the icon — it's the most ownable and reinforces "Etch" as a verb — with the lowercase "etch" + route flourish as the wordmark. A designer would refine curve tension, the squircle grid, and optical spacing for production.
